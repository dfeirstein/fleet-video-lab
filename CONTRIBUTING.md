# Contributing

Small, focused pull requests are welcome.

- **Run before you push:** `make lint`, `make demo-dry`, `bash tools/scan_private.sh` (CI runs all three plus
  `tools/doctor.py`).
- **Tool contract:** a new tool answers `--help` without keys, reads keys only from env vars (via
  `tools/_common.py: need_key`), finds binaries on PATH, works on a `--project` folder, and, if it calls a paid
  API, logs every call to a ledger under `takes/` and has a `--dry-run` that makes a placeholder of the right shape.
- **No media in git:** placeholders are generated by ffmpeg at run time. No file over 2 MB, no keys, no absolute
  home-directory paths, no client or brand material.
- **Versions:** when you change a pinned version or an endpoint, resolve it from the live source and update the
  table in `docs/SETUP.md` with the URL and the date.
- **Method changes** go in `docs/METHOD.md` with the evidence (a measurement or a frame), not just the rule.
